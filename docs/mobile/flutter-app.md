# Aplicación Móvil

La aplicación móvil desarrollada en **Flutter** permite a los operadores recibir notificaciones push de las alertas analizadas por la IA.

## Características
- Autenticación OIDC con `flutter_appauth`.
- Enlace profundo con `app_links`.
- Visualización de alertas en tiempo real y estado de infraestructura.
